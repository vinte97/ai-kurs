Подключи учебный MCP-сервер через мой персональный MCP.json. Первым сообщением спроси: «Какой IP-адрес MCP-сервера сегодня сообщил преподаватель? Если порт отличается от 8765, укажите его тоже». Дождись ответа, прежде чем менять MCP.json или подключаться. Адрес не угадывай и не подставляй из прежних настроек.

Для новой записи также спроси учебное имя для панели, вымышленный логин на .test и отдельный учебный пароль от 8 символов. Пример логина — irina@severprom.test. Если запись уже настроена и меняется только IP или порт, сохрани прежние учётные данные.

Найди MCP.json, который читает моё приложение. Добавь или обнови запись severprom, сохранив остальные настройки. Используй Streamable HTTP и URL http://<IP преподавателя>:8765/mcp. Если преподаватель указал другой порт, используй его. Для mcpServers используй формат клиента. В собственном mcp.json VS Code используется servers и type: http. Если приложением управляют через настройки, используй штатные поля URL и заголовков.

В Authorization запиши Basic, один пробел и Base64 от строки логин:пароль в UTF-8. В X-Display-Name запиши учебное имя в URL-кодировке UTF-8 как результат encodeURIComponent. Используй значения только для настройки. Не выводи пароль или Authorization в ответе и журнале, не сохраняй их или персональный MCP.json в общем репозитории. Base64 обратим. Для HTTP используй доверенную учебную сеть и отдельный учебный пароль.

Переподключи сервер, вызови lab_ping и затем whoami. Проверь profile.name и profile.email по моим учебным данным. Сервер создаёт учётку при первом подключении. При несовпадении остановись и сообщи о проблеме. На клиенте не устанавливай сервер, Python или базу. Во время настройки не отправляй письма и не меняй заметки. Сообщи результат без секретов.
