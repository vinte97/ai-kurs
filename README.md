# Учебный портал

Публичный адрес задаётся в `site.config.json` и `js/config.js`.
Страницы ссылаются друг на друга относительными адресами.
Поэтому будущий собственный домен не требует переделки страниц: меняются два адреса в конфиге и заново создаются QR-коды.

Сейчас фаза `precourse`. В сборку GitHub Pages входят только главная, подготовка, заглушки дней, дополнительные ответы и картинки QR.
Тексты заданий, запросы и архив курса в эту сборку не входят.

Снимков окон программ пока нет. Список: `MISSING-SCREENSHOTS.md`.
