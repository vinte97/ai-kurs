# Дизайн-система портала

Токены лежат в `css/tokens.css`. Презентация может подключить тот же файл. Это рабочая палитра курса, не официальные цвета Академии TOP.

| Токен | Значение | Роль |
| --- | --- | --- |
| `--color-navy` | `#102445` | Текст кнопок-контуров, рамки |
| `--color-deep` | `#091428` | Левая панель |
| `--color-blue` | `#2878FF` | Основная кнопка и текущий пункт меню |
| `--color-cyan` | `#36D6F2` | Запасной акцент, в портале не как заливка экрана |
| `--color-violet` | `#8B5CF6` | Запасной акцент |
| `--color-paper` | `#F7FAFF` | Фон рабочей области |
| `--color-white` | `#FFFFFF` | Карточки |
| `--color-ink` | `#14233B` | Основной текст |
| `--color-muted` | `#64748B` | Вторичный текст |

Шрифт: Segoe UI, затем Helvetica Neue, затем системный. Отдельный показной шрифт презентации на портал не переносится.

Радиус карточек: 14px. Кнопка не ниже 48px. Тень карточки слабая. Ширина панели 270px. Текст дня не шире 1040px вместе с панелью.

Портал не повторяет полноэкранные кадры презентации. В папке курса отдельного файла презентации нет, поэтому общие токены заведены здесь, чтобы презентацию можно было подключить позже.

Значки — текст и одна галочка в надписи «Скопировано!». Отдельного набора иллюстраций нет. Снимки окон программ не рисуются, пока нет настоящего кадра.
