# Следующие правки курса

## День 1, упражнение 4 — заметки планёрки

Переработать практику: сейчас непонятно, что находится в документе и зачем его разбирать.

- Дать короткое описание исходных заметок до скачивания.
- Сформулировать конкретную рабочую задачу и ожидаемый результат.
- Объяснить, как сверить результат с источником; согласовать упражнение с показом преподавателя.

Содержание практики пока не изменено: требуется отдельная методическая переработка.

## День 1, упражнение 3 — тест безопасности

Реализовано: нейтральные ответы до первого выбора, компактные кнопки, неверный ответ красный, верный зелёный, пояснения к выбору. Переход дальше возможен только после верного ответа во всех вопросах.
