# Проверки подготовки

4 ноября 2026, локальная сборка.

Автоматические проверки `tests/run_browser.py` прошли: главная с заголовком «ИИ для руководителей v2», старт подготовки, Windows, Mac, сохранение шага после обновления, неверный и верный код, скрытие поля после верного кода, закрытый день, меню на узком экране, копирование запроса.

Отдельно пройден мастер:

- «Начать подготовку» открывает выбор компьютера.
- Windows показывает «Этап 1 из 6», следующий экран — «Этап 2 из 6. Устанавливаем WorkAI».
- «Не получается?» открывает подсказку этого шага и кнопку «Скопировать описание проблемы».
- «Начать сначала» возвращает к приветствию.
- «Я уже всё установил» после выбора Mac открывает учебные файлы, а не установку.
- У четырёх дней в меню разные значки.
- Поле кода после кода дней 1–2 скрыто.

Снимки: `docs/prep-shots/welcome-desktop.png`, `welcome-phone.png`, `help-open.png`, `large-text.png`, `contrast.png`, `home-nav.png`, `partners.png`.

Не делалось: установка WorkAI, Git и Python на чистой Windows и на Mac. Окна установщиков по-прежнему не сняты. Трое описанных в задании профилей живых людей инструкцию не проходили, поэтому фраза «человек пройдёт без преподавателя» не считается доказанной.
