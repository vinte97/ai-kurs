# Как устроена практика

Отдельного React-приложения нет. Страницу по-прежнему собирает `tools/build_site.py`. Пошаговый режим рисует `js/lesson.js` из `js/course.js`.

| Часть | Где живёт |
| --- | --- |
| Обзор дня | экран `#lesson-app`, кнопка «Начать первое задание» |
| Шаг упражнения | один экран: действие, синяя кнопка, «Назад», «Не получается?» |
| Карточка запроса | блок «Ваш запрос» или текст промпта. Копируется только сам запрос |
| Конструктор РКФОП и роли | поля задания `refine` и `helper`. «Восстановить исходный пример» возвращает исходные значения |
| Файл | «Скачать файл», «Посмотреть содержимое», «Как найти скачанный файл?» |
| Помощь | текст текущего шага и «Скопировать описание проблемы» без пароля и ключа |
| Проверка | чек-лист с подписью, что это отметка человека. Карточки безопасности сверяются с записанными ответами |
| Итог дня | `#check`. Кнопка завершения не открывает следующий день |
| Весь день списком | «Посмотреть все задания» показывает прежние секции |
| Размер текста и контраст | те же значения, что в подготовке: `aikurs-reading-v1` |

Прогресс подготовки в `aikurs-progress-v1` не трогается. Практика хранится отдельно, в `aikurs-lesson-v1`. Сброс «Начать заново» чистит только текущее задание.
