# Оформление портала

Это цвета проекта, не официальная палитра Академии TOP.

Токены лежат в `css/tokens.css`.

| Токен | Значение | Где |
| --- | --- | --- |
| `--color-deep` | `#091428` | Боковая панель |
| `--color-navy` | `#102445` | Тёмные элементы |
| `--color-blue` | `#2878FF` | Основная кнопка и текущий раздел |
| `--color-cyan` | `#36D6F2` | Запасной акцент, в текущих экранах почти не нужен |
| `--color-violet` | `#8B5CF6` | Запасной акцент |
| `--color-paper` | `#F7FAFF` | Фон рабочей области |
| `--color-white` | `#FFFFFF` | Карточки |
| `--color-ink` | `#14233B` | Текст |
| `--color-muted` | `#64748B` | Вторичный текст не мельче 14 px |

Шрифт: Manrope, запасной Segoe UI. Основной размер 18 px. Заголовок страницы 36 px. Подзаголовок раздела 26 px.

Панель слева 270 px. Радиус карточек 14 px. Кнопки не ниже 48 px.

На ширине до 800 px панель скрыта. Её открывает кнопка «Меню», закрывают «Закрыть», подложка и Escape. После закрытия фокус возвращается на «Меню».

Логотипы партнёров и чужие снимки окон не используются.
