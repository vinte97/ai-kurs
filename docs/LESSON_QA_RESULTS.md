# Проверка практики

Автоматические проверки после сборки прошли: `python3 tests/check_site.py` и `python3 tests/run_browser.py`.

Браузер проверил:

- новый вход в день 1, одно действие, возврат на обзор;
- копирование письма целиком, без заголовка карточки;
- конструктор РКФОП: изменённое поле попадает в буфер, квадратные скобки не копируются;
- копирование с клавиатуры;
- отказ буфера обмена показывает «Не удалось скопировать», кнопка не становится «Скопировано!»;
- ссылка на учебный файл отвечает, на шаге есть объяснение папки «Загрузки»;
- после «Продолжить» и перезагрузки остаётся шаг «Вставьте запрос»;
- ширина 375 px без горизонтальной прокрутки, синяя кнопка на экране;
- в сборке закрытого дня нет адреса `127.0.0.1`, `token=` и запросов следующих дней.

Отдельно открыты дни 1–4: обзор строится, ошибок JavaScript нет.

Смотрел глазами снимки в `docs/lesson-shots/`: обзор, шаг, запрос, конструктор, файл, помощь, телефон, крупный текст.

Не проверялось живым человеком, программой чтения с экрана и автоматическим axe. Контраст считался по уже принятой палитре, отдельный замер пар цветов не делался. Снимки окон WorkAI к шагам не прикладывались: их нет в проекте.
