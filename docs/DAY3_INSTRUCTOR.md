# Запуск учебного сервера и подключение агента

## Преподавателю · Windows

1. Получите у организатора архив `severprom-mcp-windows.zip` и распакуйте его целиком в свою папку. Для первой установки нужен интернет.
2. Откройте папку `severprom-mcp-lab` и запустите `setup-and-run.bat`. Он установит uv, если его ещё нет, подготовит Python и зависимости, создаст базу и загрузит учебный архив СеверПрома.
3. Когда скрипт спросит IPv4, введите текущий адрес компьютера преподавателя в учебной сети. В Windows адрес можно посмотреть командой `ipconfig` в разделе активного Wi‑Fi или Ethernet. Если нажать Enter, сервер будет доступен только на этом компьютере.
4. Откройте [панель преподавателя](http://127.0.0.1:8765/admin) на компьютере, где запущен сервер. В разделе **«СеверПром · учебные профили»** доступны письма и заметки, в том числе материалы Лебедевой и Медведева.
5. Сообщите участникам текущий IP. Скрипт выведет готовый адрес MCP вида `http://<IP>:8765/mcp`. Участники должны быть в сети, из которой доступен этот адрес. Если Windows спросит о доступе, разрешите входящее подключение в доверенной учебной сети. Для проверки с ноутбука участника откройте `http://<IP>:8765/healthz`.

Держите окно запуска открытым. Остановка — Ctrl+C. На следующем занятии запустите тот же файл и введите актуальный IPv4. Учётные записи, письма и заметки хранятся в папке `data` и сохраняются при повторном запуске. Панель без пароля доступна с компьютера преподавателя.

## Участнику · текст для копирования агенту

> Подключи учебный MCP-сервер через мой персональный MCP.json. Сначала спроси актуальный IP сервера у участника и дождись ответа, прежде чем менять MCP.json или подключаться. Если преподаватель назвал другой порт, уточни его. Для нового подключения спроси учебное имя, вымышленный логин на .test и отдельный учебный пароль от 8 символов. Пример логина — irina@severprom.test.
>
> Найди MCP.json, который читает моё приложение. Добавь или обнови запись severprom, сохранив остальные настройки. Используй Streamable HTTP и URL http://&lt;IP преподавателя&gt;:8765/mcp. Если преподаватель указал другой порт, используй его.
>
> В заголовок Authorization запиши Basic и через пробел Base64 от строки логин:пароль в UTF-8. В заголовок X-Display-Name запиши учебное имя в URL-кодировке UTF-8, как результат encodeURIComponent. Используй полученные значения только для настройки. Не выводи пароль или заголовок Authorization в ответе и не записывай их в общий репозиторий.
>
> Переподключи сервер и вызови lab_ping, затем whoami. Проверь, что имя и учебный адрес совпадают. Сервер создаст учётку при первом подключении. При смене IP обнови URL в существующей записи, сохранив прежние логин и пароль. Во время настройки не отправляй письма и не меняй заметки.

### Справка по формату MCP.json

Пример для клиентов с ключом `mcpServers`. В собственном `mcp.json` VS Code используется ключ `servers` и поле `"type": "http"`. Если приложение управляет MCP через настройки, используйте соответствующие поля адреса и заголовков.

```json
{
  "mcpServers": {
    "severprom": {
      "url": "http://<IP>:8765/mcp",
      "headers": {
        "Authorization": "Basic <BASE64_ЛОГИН_ДВОЕТОЧИЕ_ПАРОЛЬ>",
        "X-Display-Name": "<URL_ENCODED_ИМЯ>"
      }
    }
  }
}
```

Для локального HTTP используйте отдельный учебный пароль. Base64 обратим.

### Если подключение не получилось

| Что видно | Что проверить |
|---|---|
| `/healthz` не открывается | Запуск сервера, сегодняшний IP, общую сеть, доступ к порту 8765. |
| MCP отвечает 401 | Логин на .test, исходный пароль и два заголовка. При первой регистрации имя обязательно. |
| Участник не появился в панели | Обновите страницу и проверьте, что клиент успешно вызвал `whoami`. |
| Интернет-поиск недоступен | Для живой выдачи Википедии компьютеру преподавателя нужен доступ в интернет. |

После подключения агент может читать и отправлять учебную почту, сохранять и искать заметки и выполнять веб-поиск. Для поиска в архиве СеверПрома передайте `include_knowledge=true` в `notes_search`.
