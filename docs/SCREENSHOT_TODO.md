# Каких снимков нет

На сайте нет нарисованных окон вместо настоящих.

В шагах загрузки уже стоят снимки живых страниц от 2 ноября 2026: WorkAI для Windows и Mac, Git для Windows, Python для Windows и Mac. Это снимки сайтов, не окон установки на компьютере.

Полный список кодов шагов, для которых нужен снимок, уже был в `MISSING-SCREENSHOTS.md`. Он остаётся списком дел. Когда снимок появится, его кладут в `images/` и показывают в поле «Что вы увидите» только если это фото настоящего окна.

Отдельно нет снимка кнопки отправки в WorkAI. В инструкции она названа «кнопка отправки рядом с полем сообщения», без картинки.
