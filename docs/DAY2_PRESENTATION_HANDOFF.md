# Отличия сайта для синхронизации показа

1. Локальные папки: «СеверПром» и соседняя «Результаты», относительно уже открытой
   учебной папки. URL https://github.com/cursorstudent-course/company.git сохраняется.
2. Первый промпт каждой практики — связное поручение без текстовых меток РКФОП.
   На сайте метки вынесены в раскрываемое пояснение, в буфер не попадают.
3. Источники основных практик берутся из актуального day2prompts.ts, без перевода
   в старую автономную 14-День_2_практики. Полный перечень — в alignment.json.
4. Практика 8: новое основание —
   СеверПром/01-Документы/2026-11-11_Изменение_лимита_визита.md.
   Первые два входа — принятые результаты 11 и 12; сначала согласуется план,
   затем обновляются затронутые файлы. Исходники не меняются.
5. Практика 10: «Текст_для_проверки.md» скачивается с сайта:
   files/day2/Текст_для_проверки.md. Это непроверенный учебный текст, исправленный
   ответ не опубликован. Старый путь внутри 14-День_2_практики больше не используется.
6. Тетрадь скачивается как files/day2-workbook.md; весь комплект —
   files/day2-workbook.zip, запросы — files/day2-prompts.txt.
7. Практики 8–10 без «если осталось время». Выбор упражнений остаётся преподавателю.
8. PDF строится из принятого Markdown отдельно от DOCX. HTML-доклад в
   Результаты/Доклад/index.html открывается двойным щелчком, без сервера и зависимостей.
9. Окончательные пути сверены с Manifest_путей.csv, исправляющий коммит
   df85e49a75eecbc5e8356aafbeed9970aa00ee9c проверен в свежей копии GitHub.
10. Обновить в показе имена расходов и бланков:
    СеверПром/04-Таблицы/Расходы_август_октябрь_2026.xlsx,
    СеверПром/04-Таблицы/Описание_расходов_август_октябрь_2026.md,
    СеверПром/12-Шаблоны/Записка_о_готовности_визита.md и .docx.
    Текущий day2prompts.ts уже содержит эти имена; сайт с ним сверён.

Копирование — только на учебном сайте; презентация остаётся показом преподавателя.
