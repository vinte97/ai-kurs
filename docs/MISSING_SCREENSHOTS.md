Не подменять этот список нарисованными окнами.

Уже есть живые снимки страниц от 2 ноября 2026: загрузка WorkAI для Windows и Mac, вход по почте, регистрация по почте, страница Git для Windows, страницы Python для Windows и Mac.

Нет и не публикуется как будто есть:

- Окно Git: Next, Finish и сообщение об успехе.

- Кнопка отправки сообщения внутри WorkAI.
- Меню «Пуск», «Проводник» и папка «Загрузки»: это окна системы, их нельзя честно снять с сайта загрузки.
