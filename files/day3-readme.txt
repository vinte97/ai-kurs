ПОДКЛЮЧЕНИЕ MCP «СЕВЕРПРОМ»

На клиенте нужен WorkAI или другой MCP-клиент с Streamable HTTP. Сервер, Python и базу на ноутбук участника не устанавливают.
В текущей конфигурации: http://192.168.0.106:8765/mcp. Перед подключением адрес подтверждает преподаватель. localhost клиента использовать нельзя. Для проверки сети: http://192.168.0.106:8765/healthz; нужен доступ по TCP-порту 8765.
Authorization: Bearer <персональный токен>. Один пробел после Bearer. Токен выдаётся отдельно и вводится в защищённых настройках; в чат, URL, отчёты и проект не попадает. Сайт токены не принимает и MCP-вызовы не выполняет.
Сначала проверьте только чтением: lab_ping, whoami (своя метка student-XX), mail:read/notes:read/assignments:read, mail_list limit=5, list_assignments VISIT-101–VISIT-105, get_assignment TEST-999 (NOT_FOUND). Нет прав или чужая метка — остановитесь.
401 — авторизация; 421/403 — преподаватель проверяет Host/Origin, защиту не отключают; PERMISSION_DENIED — не хватает права. Каталог без whoami/поручений обновите, затем обратитесь к преподавателю.
HTTP передаёт данные без шифрования: используйте только доверенную учебную сеть.
Запись и отправка — только отдельная практика с отдельным подтверждением. delivered_virtual — запись в своей песочнице, не доставка в реальную почту или другому участнику. При недоступном обмене сохраните черновик.
Результаты сохраняйте в Результаты/День_3; тетрадь хранится у вас. Сайт сохраняет только отметки в этом браузере.
