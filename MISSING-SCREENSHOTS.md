# Недостающие снимки экрана

Настоящих снимков окон WorkAI, Windows и macOS в проекте нет.
Случайные картинки вместо них не подставлены.
Когда снимок появится, положите файл в `images/` и уберите фразу «Снимка этого окна пока нет» у этого шага.

| Код | Что снять |
| --- | --- |
| w-open | Страница https://workai.su/download, заголовок «Скачать WorkAI» |
| w-click | Кнопка «Windows (.exe)» |
| w-wait | Законченная загрузка в браузере |
| w-start | Кнопка «Пуск» |
| w-explorer | Пункт «Проводник» |
| w-downloads | Папка «Загрузки» в Windows |
| w-file | Файл установщика .exe |
| w-run | Окно установки WorkAI и синее окно Windows |
| w-install | Конец установки WorkAI |
| w-launch | Окно запущенной WorkAI |
| g-open | Фраза Click here to download на git-scm.com |
| g-click | Загрузка Git |
| g-search | Поиск папки «Загрузки» через «Пуск» |
| g-downloads | Файл Git в папке «Загрузки» |
| g-run | Окно установки Git с кнопкой Next |
| g-next | Кнопка Finish |
| p-open | Ссылка Download Windows installer (64-bit) |
| p-click | Файл python-….exe |
| p-run | Открытый файл python-….exe |
| p-path | Галочка Add python.exe to PATH |
| p-install | Надпись Setup was successful |
| m-apple | Значок яблока |
| m-about | Пункт «Об этом Mac» |
| m-chip | Строка Chip или «Чип» |
| m-open | Страница загрузки WorkAI на Mac |
| m-click | Кнопки macOS Apple Silicon и macOS Intel |
| m-finder | Значок Finder |
| m-downloads | Папка «Загрузки» на Mac |
| m-dmg | Открытый файл .dmg |
| m-install | Окно, где программу переносят в «Программы» |
| m-launch | Запуск WorkAI на Mac |
| mp-open | Ссылка Download macOS installer |
| mp-click | Файл .pkg |
| mp-run | Успешная установка Python на Mac |
| mg-note | Этот шаг без снимка: отдельной простой установки Git для Mac на официальном сайте нет |
| u-windows | Кнопка Windows на нижней полосе |
| u-mac | Яблоко в левом верхнем углу |
