# AI Kurs — дизайн-система

Один источник цветов и размеров: `design-system/tokens.json`. Портал читает те же значения из `css/tokens.css`.

Портал — для самостоятельной работы. Презентация — для проектора. Шрифт и палитра общие. Размеры на слайде крупнее, чем на сайте.

## Шрифт

Inter, начертания 400–700. Если шрифт не загрузился: `system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif`.

Файлы SF Pro в проект не кладутся. Для кода — `ui-monospace`.

На портале основной текст 18 px, кнопки не ниже 48 px. Заголовок страницы около 36–40 px.

## Цвет

Светлая тема по умолчанию.

- Фон `#F5F5F7`, карточка `#FFFFFF`, второй уровень `#F0F2F5`.
- Текст `#1D1D1F`, вторичный `#5B616D`.
- Главное действие `#0066CC`, наведение `#0057B8`.
- Декоративный `#2878FF` не используется для мелкого текста.

Тёмная тема и режим «Система» переключаются в меню. Выбор хранится в `aikurs-theme-v1`. Повышенный контраст включается отдельно и не сбрасывает тему.

## Стекло

Размытие только у бокового меню. Текст заданий, промпты и файлы лежат на непрозрачной карточке.

При `prefers-reduced-transparency` меню становится сплошным. При `prefers-reduced-motion` короткие переходы отключаются.

## Кнопки

На экране одно синее действие. «Назад» и похожие шаги — серая заливка. Редкие действия — без заливки.

«Скопировано!» появляется только после удачной записи в буфер.

## Презентация

Файл токенов скопирован в `presentation-review/source/design-system/tokens.json`. Слайды по-прежнему собраны на тёмном холсте и своих шаблонах. Восемь композиций из спецификации в колоду ещё не перенесены.
